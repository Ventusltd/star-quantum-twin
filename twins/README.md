# Rule twins

A rule joins the Quantum Twin Star only with its twins:
- **principal:** the rule, in one statement;
- **twin:** the measured reality that makes it true, with numbers. Agreement between two things built here proves consistency, not truth, so at least one twin comes from measurement;
- **positron:** the observations that would make it false. Each one can be tested;
- **witnesses:** independent agents who were asked to refute it, with their verdicts.

Coupling is measured, not asserted: each clause of the principal names the check that holds it.
